# BREACH_01 — Operation Black Vault

## Starten

Open `index.html` rechtstreeks in een recente browser, bijvoorbeeld Chrome of Edge. Een server, installatie en internetverbinding zijn niet nodig. Alles is een fictieve simulatie; er worden geen echte systemen of shellcommando's gebruikt.

## Spelen

Start de missie en onderzoek de terminal met `help`, `scan` en `inspect auth`. Gebruik eventueel de hints. Probeer daarna in te loggen, open de code-editor en pas de operator aan. Met **TEST REPARATIE** controleer je de oplossing; de afzonderlijke resultaten zijn op aanvraag zichtbaar.

Na de hoofdmissie kun je optioneel twee Python-puzzels spelen. Vul telkens alleen de ontbrekende operator in en test de uitkomst. Dit is een simulatie met een beperkte set operators, geen volledige Python-interpreter; er wordt geen ingevoerde code uitgevoerd.

Je kunt ook de netwerkbonus kiezen: selecteer een fictieve firewallregel en test of de beheercomputer wel en een onbekende computer geen toegang krijgt. De netwerkbonus verandert geen echte netwerk- of firewallinstellingen.

## Opnieuw beginnen

**HERSTART** brengt je vanuit elk scherm terug naar het begin. Na voltooiing doet **NIEUWE MISSIE** hetzelfde. Terminalgeschiedenis, invoer, hints, operator en testresultaten worden gewist. Voortgang staat alleen tijdelijk in het browsergeheugen; ook na herladen begin je opnieuw.
